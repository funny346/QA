 тесты написанные на pytest для проверки:
 1) сложения
 2) деление на 0
 3) очистка истории калькулятора
 Для работы нужно скачать библиотеку Pytest. Как скачать: Нажимаем на иконку меню -> File -> Settings -> Project: имя вашего проекта -> Python Interpreter -> Add Interpreter -> В поиске ищем "pytest" -> устанавливаем и ждём загрузки

ИЛИ

Откройте терминал внизу среды разработки и выполните команду:

pip install pytest

Запуск:

Чтобы запустить процесс тестирования, откройте терминал в корневой папке проекта и выполните команду:

pytest test_calculator.py -v

*Флаг "-v" (verbose) покажет детальный отчет по каждому отдельному тесту.*
